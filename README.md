# Task 5 – Data Analysis on CSV Files

This project performs basic data analysis on a sales dataset using Python and Pandas.

## 🚀 Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 📂 Files Included
- sales.csv — Sample sales dataset
- main.py — Script for data analysis & chart generation
- analysis.ipynb — Notebook with analysis steps
- requirements.txt — Dependencies list

## 📊 Analysis Performed
- Loaded CSV using Pandas
- Added "Revenue" column
- Grouped data by Product
- Visualized:
  - Revenue by product (Bar Chart)
  - Daily revenue trend (Line Chart)

## 📸 Output Charts
- revenue_by_product.png
- daily_trend.png

## 📥 How to run
```bash
pip install -r requirements.txt
python main.py
